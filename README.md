# 📘 সবুজ বই (Sabuj Boi)

বাংলাদেশ সরকারের প্রকল্প প্রণয়ন, অনুমোদন, PPR 2025 এবং বিবিধ নির্দেশিকা সংক্রান্ত একটি আধুনিক, রেসপন্সিভ ওয়েব অ্যাপ্লিকেশন।

## 🚀 বৈশিষ্ট্যসমূহ (Features)
- **স্মার্ট সার্চ:** অনুচ্ছেদ, চ্যালেঞ্জ, সিস্টেম এবং PPR 2025-এর জন্য অত্যাধুনিক লাইভ সার্চ।
- **PPR 2025:** ১৫০টি সমস্যা ও সমাধানের বিস্তারিত তালিকা (স্মার্ট অধ্যায় ফিল্টারসহ)।
- **২৫টি চ্যালেঞ্জ:** IMED কর্তৃক চিহ্নিত প্রকল্প বাস্তবায়নের চ্যালেঞ্জ ও সমাধান।
- **PWA সাপোর্ট:** মোবাইল ও ডেস্কটপে অ্যাপের মতো ইনস্টল করে অফলাইনে ব্যবহারের সুবিধা।
- **রেসপন্সিভ ডিজাইন:** মোবাইল, ট্যাব এবং ডেস্কটপে নিখুঁতভাবে কাজ করে।

## 🛠️ প্রযুক্তি (Tech Stack)
- **Backend:** Python 3.13, Flask 3.0.0
- **Frontend:** HTML5, CSS3, Vanilla JavaScript, Bootstrap 5.3
- **ডেটাবেস:** JSON (SQLite/DB ব্যবহার করা হয়নি)
